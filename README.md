# chalk-talk → house-lights

**This repository moved.** chalk-talk is one of the five skills of
[house-lights](https://github.com/ruinosus/house-lights). Install it from there:

```
/plugin marketplace add ruinosus/house-lights
/plugin install house-lights@house-lights
```

If you installed `chalk-talk` from this repository, remove it: `/plugin uninstall chalk-talk@chalk-talk`. Its files keep working
with the new skill. The gallery is now https://ruinosus.github.io/house-lights/chalk-talk/; the npm command is
`npx house-lights chalk-talk <file>`. This repository is archived and keeps its history and releases.
